You will receive, in a single user turn, the following labelled sections:

  CONVERSATION SO FAR (optional — present only on follow-up turns):
  <the recent dialogue between the User and Diana, oldest to newest, for

  QUESTION is a follow-up that depends on earlier turns — e.g. "tell me

  <the user's question Diana was asked. May be a follow-up whose full

Score the answer along TWO axes, each 0.0 to 1.0:

   - 0.7  on-topic but adds related-but-unrequested context.
   - 0.4  partly on topic; misses a major part of the question.

Return JSON only, no surrounding prose or markdown fences. The exact shape MUST be:

{
  "faithfulness": <float 0.0-1.0>,

Rules:
- Round each float to 2 decimal places.
- rationale ≤ 280 characters.
- Never include keys other than the three above.
- If the answer is a refusal that is appropriate to the question (e.g. user asked about something private/unrelated and Diana politely declined), score answer_relevance=1.0 and faithfulness=1.0.
